# 解析工作台密度与批量打开体验设计

## 目标

让视频解析工作台将首屏空间优先留给单条/批量解析输入与结果，并确保在批量任务中打开完成项时不改变用户当前的滚动位置；创作工具默认以简体中文为目标语言。

## 范围

### 1. 紧凑的解析页顶部（A 方案）

- 保留 `VIDEO WORKSPACE`、`带来链接，留住此刻。` 和能力说明，维持品牌识别。
- 将顶部容器的纵向内边距和标题区下边距缩小约一半。
- 将主标题改为辅助级标题：桌面约 30px、移动端约 26px；说明文字收紧为单行优先的简短描述。
- 不改变单条/批量切换、输入表单、解析结果或页面整体视觉主题。

### 2. 批量结果“打开”保持位置

- 点击批量任务项的“打开”仍加载对应的历史解析记录和视频信息。
- 当用户已经处于 `/parse` 时，不再重复执行路由导航，也不调用页面级 `scrollTo({ top: 0 })`。
- 从个人中心、首页或其他页面进入解析页时，仍保持原有“进入新页面时回到顶部”的导航行为。
- 加载失败时继续在当前解析页显示现有错误提示。

### 3. 创作包默认简体中文

- 创作包的目标语言默认值由 `en` 改为 `zh-CN`。
- 已保存的历史解析记录若含 `translation_language`，优先恢复该历史选择，不覆盖用户已有内容。
- 下拉选项和后端请求字段保持不变。

## 实现边界

- 只修改前端 React 组件、相关导航测试与创作工具默认值；不修改后端 API、数据库或套餐规则。
- 不新增第三方依赖、图片或动画。

## 验收

1. 解析页首屏在桌面与移动尺寸下，输入/模式切换区域明显上移且文案仍可读。
2. 在批量结果区域滚动后点击“打开”，页面滚动位置不变，结果内容会被载入。
3. 直接访问 `/parse` 或从其他页面导航到 `/parse` 时，仍从页首开始。
4. 新解析记录首次打开创作包时，语言选择显示“简体中文”；历史记录保留已存语言。
5. 相关前端单元测试与生产构建通过。
