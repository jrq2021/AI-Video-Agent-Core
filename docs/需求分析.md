# 需求分析文档

> **项目名称**：AI Video — 万能视频下载 & AI 智能分析平台  
> **版本**：v1.0.0  
> **更新日期**：2026-05-17

---

## 一、项目背景

现在很多用户有下载保存视频到本地的需求，但部分视频无法直接通过平台下载（平台自身不支持下载功能），或者下载方式不够便捷——比如不支持批量下载、存在各种限制、清晰度有限等。因此，需要开发一个**万能视频下载网站**，让用户能够更快速、随时随地地从各个平台下载视频，手机上也能使用。

此外，还可以按需扩展一些增值功能，如：视频内容 AI 总结、字幕翻译、付费能力等，提升产品的差异化和商业价值。

## 二、功能需求

### 2.1 核心功能

| 模块               | 功能点                                                      | 优先级 | 说明                                            |
| ------------------ | ----------------------------------------------------------- | ------ | ----------------------------------------------- |
| 🌐 **多平台解析**  | 支持 Bilibili、抖音、YouTube、TikTok 等主流平台视频链接解析 | P0     | 获取视频标题、封面、UP 主、播放量、时长等元数据 |
| 🎥 **视频下载**    | 支持多清晰度选择下载（1080p/720p/480p 等）                  | P0     | 实时 SSE 推送下载进度（百分比、速度、剩余时间） |
| 📝 **字幕提取**    | 优先使用官方字幕；无官方字幕时自动 ASR 语音识别兜底         | P0     | 支持导出 VTT / SRT / 纯文本格式                 |
| 🤖 **AI 视频总结** | 基于大模型流式生成视频内容摘要与核心要点                    | P1     | 支持 DeepSeek 等模型，SSE 流式输出              |
| 🧠 **思维导图**    | 自动提炼视频逻辑结构，生成 Markdown 思维导图                | P1     | 基于 markmap 渲染，支持缩放/拖拽交互            |
| 📋 **下载历史**    | 本地存储下载历史记录，支持一键重新解析                      | P2     | 使用 localStorage 持久化                        |

### 2.2 用户模块

| 功能点     | 优先级 | 说明                                       |
| ---------- | ------ | ------------------------------------------ |

| Token 鉴权 | P1     | JWT 有效期 72 小时，后续可用于付费功能鉴权 |
| 用户信息   | P2     | 查看/编辑个人信息                          |

## 三、非功能需求

### 3.1 性能要求

| 指标         | 要求                    | 说明                                |
| ------------ | ----------------------- | ----------------------------------- |
| API 响应时间 | < 200ms（视频信息解析） | 非下载场景的常规接口                |
| 下载速度     | 最大化利用带宽          | 使用 yt-dlp 多线程下载              |
| 并发支持     | ≥ 50 并发用户           | FastAPI 异步架构天然支持            |
| 首屏加载     | < 2s                    | Vite 构建优化 + Tailwind CSS 原子化 |

### 3.2 可用性

| 指标       | 要求                                             |
| ---------- | ------------------------------------------------ |
| 系统可用性 | 99.5%（非关键业务）                              |
| 移动端兼容 | iOS Safari / Android Chrome                      |
| 浏览器兼容 | Chrome 90+ / Edge 90+ / Firefox 90+ / Safari 15+ |

### 3.3 安全性

| 要求             | 实现方式                                   |
| ---------------- | ------------------------------------------ |
| 用户密码加密存储 | SHA-256 + 随机 Salt                        |
| API 认证         | JWT Token，72h 过期                        |
| CORS 控制        | FastAPI CORSMiddleware（生产环境限制域名） |
| 文件访问控制     | Token 鉴权，禁止目录遍历                   |
| 敏感信息保护     | API Key 通过 .env 环境变量管理             |

### 3.4 可维护性

| 要求       | 说明                                       |
| ---------- | ------------------------------------------ |
| 前后端分离 | React 前端 + FastAPI 后端，独立部署        |
| 热重载     | 开发环境前后端均支持热重载                 |
| 日志记录   | 使用 Python logging 模块                   |
| 代码规范   | 遵循 PEP 8（Python）、ESLint（JavaScript） |

### 3.5 可扩展性

- 模块化设计，新增平台解析只需添加对应爬虫模块
- AI 总结/思维导图支持切换不同大模型提供商
- 存储层可平滑迁移（本地文件 → OSS / S3）

## 四、技术约束

### 4.1 环境约束

| 约束项       | 要求                            |
| ------------ | ------------------------------- |
| Python 版本  | ≥ 3.10                          |
| Node.js 版本 | ≥ 18                            |
| 操作系统     | Windows / macOS / Linux         |
| ffmpeg       | 必须安装（音频处理 + 视频合并） |

### 4.2 依赖约束

| 依赖           | 用途               | 约束说明                                        |
| -------------- | ------------------ | ----------------------------------------------- |
| yt-dlp         | 多平台视频解析下载 | 需保持最新版本以兼容平台 API 变更               |
| faster-whisper | 本地语音识别       | 需要下载模型文件（base 约 140MB），首次启动较慢 |
| DeepSeek API   | AI 总结            | 需要有效的 API Key，存在调用频率限制            |
| static-ffmpeg  | 音频处理           | 自动下载静态二进制文件，需网络通畅              |

### 4.3 网络约束

- **国内网络环境**：部分境外平台（YouTube、TikTok）可能需要代理访问
- **B站 CDN**：下载时需绕过系统代理直连，否则可能出现 SSL 错误
- **抖音反爬**：需要维护 A-Bogus / X-Bogus 签名算法以绕过反爬机制

### 4.4 平台限制

| 平台     | 限制                                                                     |
| -------- | ------------------------------------------------------------------------ |
| Bilibili | 免费用户仅可下载 360p/480p/720p（854×394 以下）；4K/1080P 高码率需大会员 |
| 抖音     | 视频流 URL 有时效性（约 30 分钟），需及时下载                            |
| YouTube  | 受地域限制，部分视频需要代理；1080p+ 需要视频+音频分离合并               |
| TikTok   | 与抖音类似，需维护签名算法                                               |

### 4.5 法律合规

- 用户下载的视频仅供个人学习研究使用，不得用于商业用途
- 需在页面上添加版权声明和免责声明
- 用户注册时需同意服务条款

## 五、用户故事

1. **作为普通用户**，我希望粘贴一个视频链接就能看到视频信息，选择清晰度后一键下载到本地。
2. **作为学习用户**，我希望下载视频的同时能获取字幕和 AI 总结，快速了解视频内容。
3. **作为移动端用户**，我希望在手机上也能方便地粘贴链接、下载视频。
4. **作为内容创作者**，我希望通过思维导图功能快速理清视频的逻辑结构。
5. **作为付费用户**（未来），我希望获得更高清晰度、更快速率的下载服务。

## 七、创作者内容包（已实现）

- 闲鱼用户可在 `/redeem` 兑换 Pro 周卡、月卡或年卡，并在个人中心查看到期日和每日权益。
- Pro/Ultra 可使用受限单并发的批量解析：Pro 每批最多 5 条、每日最多 10 条；Ultra 每批最多 15 条、每日最多 30 条。
- 已解析的视频可生成中英双语字幕，以及标题、口播提纲、平台文案和高光时间点组成的 AI 创作包。
- 翻译与创作包各消耗一次每日创作额度；同一解析记录的缓存结果不重复扣费，失败会自动退款。
